
# PeopleHub - React User Dashboard

## About
PeopleHub is a responsive user dashboard built with React and Vite.
It fetches user information from a public REST API.

## Features
- Fetch users from an API
- Search by name, email, or city
- Display user email, city, and company
- Loading and error messages
- Responsive layout

## Technologies Used
- React
- Vite
- JavaScript
- CSS
- Fetch API
- JSONPlaceholder REST API
- Git and GitHub

## API
https://jsonplaceholder.typicode.com/users

## Run Locally
1. Install Node.js.
2. Clone this repository.
3. Open the project folder in a terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL shown in the terminal.

## Production Build
Run `npm run build`.

## Deployment
Deployed using Vercel.
